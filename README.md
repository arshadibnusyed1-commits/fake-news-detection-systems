# Fake News Detection System

## About the Project
The Fake News Detection System is a web application developed using Python and Machine Learning to help users identify potentially fake news articles.

## Features
- Fake news classification using Machine Learning
- TF-IDF text feature extraction
- Logistic Regression model
- Web interface built with Flask
- User login and registration
- Prediction history stored using SQLite
- Trusted news source verification feature

## Technologies Used
- Python
- Flask
- Scikit-learn
- Machine Learning
- TF-IDF
- Logistic Regression
- SQLite
- HTML
- CSS
- JavaScript

## Model Performance
The model achieved 94.88% accuracy on the test dataset used in this project.

## How to Run
1. Install Python.
2. Install the required Python packages.
3. Run the Flask application.
4. Open the local application URL in your web browser.

## Project Purpose
This project demonstrates how Machine Learning and Natural Language Processing techniques can be applied to news text classification.
